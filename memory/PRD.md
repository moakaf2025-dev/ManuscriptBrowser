# مسطرة قراءة المخطوطات — PRD

## المشكلة الأصلية
أداة بسيطة (سطح مكتب/ويب) تساعد الباحث أثناء قراءة المخطوطات: تعرض صورة أو PDF مع مسطرة أفقية شفافة تُحرَّك يدوياً سطراً سطراً لتوجيه النظر. **بدون أي ملف صوتي، بدون مزامنة، تحريك يدوي فقط.**

## البنية
- Frontend: React (Web) — يعمل كتطبيق ويب داخل المتصفح، وقابل للتغليف لاحقاً كتطبيق ويندوز عبر Electron/Tauri.
- Backend: FastAPI (بلا استخدام فعلي حالياً — الأداة تعمل بالكامل على العميل).
- PDF: مكتبة `pdfjs-dist` v4.8.69 مع Web Worker.
- التخزين: `localStorage` لحفظ إعدادات الجلسة الأخيرة (الملف الحالي، الصفحة، الزوم، موضع المسطرة، لون/شفافية/ارتفاع/قفزة المسطرة، التعتيم).

## المكوّن الرئيسي
- `/app/frontend/src/components/ManuscriptRuler.jsx`

## ما تم إنجازه (15 يناير 2026)
- شاشة رئيسية واحدة بلا تعقيد.
- دعم فتح صور (JPG/PNG/TIFF/BMP/WebP/GIF) وملفات PDF.
- مسطرة أفقية شفافة تتحرك يدوياً:
  - سحب بالفأرة.
  - نقر على أي موضع في الصفحة لنقل المسطرة إليه.
  - أسهم لوحة المفاتيح (↓/↑) مع قفزة سطر قابلة للضبط.
- تعتيم قابل للضبط لما فوق وتحت المسطرة (تقليل التشتت).
- تكبير/تصغير (9 مستويات: 50%–300%) عبر أزرار أو `Ctrl+/−` أو `Ctrl+عجلة الفأرة`.
- تدوير 90° (زر أو مفتاح `R`).
- التنقل بين صفحات PDF (`Page Up`/`Down` أو أزرار).
- إظهار/إخفاء المسطرة (`H`).
- وضع ملء الشاشة (`F11`).
- لوحة إعدادات: لون المسطرة، الشفافية، الارتفاع، قفزة السطر، مقدار التعتيم.
- نافذة اختصارات لوحة المفاتيح (مفتاح `؟`).
- حفظ تلقائي للجلسة عند كل تغيير.
- تصميم عربي بالكامل RTL بألوان بنية دافئة (ورق ومداد) وخط Amiri/Reem Kufi.

## المستخدم المستهدف
- الباحثون والمحققون في المخطوطات، طلاب الدراسات العليا في المخطوط، القرّاء الطويلون للنصوص المصوّرة.

## الاختبار
- تم اختبار: فتح PDF (3 صفحات) — تحريك المسطرة بالأسهم — التنقل بين الصفحات — التكبير — لوحة الإعدادات — نافذة الاختصارات.

## قائمة الميزات القادمة (اختيارية)
- P1: علامة مرجعية سريعة لكل ملف.
- P1: ضبط تباين/سطوع.
- P2: نمط ليلي/فاتح للواجهة.
- P2: تخصيص الاختصارات.
- P2: تغليف كتطبيق ويندوز عبر Electron/Tauri وإصدار ملف تثبيت `.exe`.
- P3: فتح ملفين جنباً إلى جنب للمقابلة البصرية.

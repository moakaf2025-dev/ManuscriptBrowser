# متصفح المخطوطات — PRD

## المشكلة الأصلية
أداة سطح مكتب متخصصة لباحثي المخطوطات لعرض الصور/PDF بجوار مسطرة أفقية شفافة، مع دعم فك ضغط الأرشيفات (ZIP/RAR)، تقسيم الصفحات المزدوجة، ترقيم الأوراق (1/أ، 1/ب)، بطاقة وصف المخطوط، تعليقات، عناوين، تصدير Word/PDF، ولقطات مع شرح.

## البنية
- Frontend: React (CRA) — يُغلّف كتطبيق Windows Portable عبر Electron 33.
- Backend: FastAPI — نقطة `/api/download/windows` لتنزيل الحزمة.
- PDF: `pdfjs-dist` + `pdf-lib`.
- الأرشيفات: `libarchive.js` (WASM).
- التخزين: `localStorage` مُعزَّل عبر بادئة NS للوحات جنباً إلى جنب.

## المكوّنات الرئيسية
- `/app/frontend/src/App.js` — SplitView Entry
- `/app/frontend/src/components/SplitView.jsx` — عرض جنباً إلى جنب (1 أو 2 لوحات).
- `/app/frontend/src/components/ManuscriptRuler.jsx` — قلب التطبيق (~3600 سطر).
- `/app/desktop/main.js` — نقطة Electron.
- `/app/backend/server.py` — نقطة `/api/download/windows`.

## ما تم إنجازه (19 يوليو 2026 — إعادة هيكلة v1.5.0)
- **إعادة هيكلة كاملة لشريط الأدوات**: من ~15 زر صغير إلى 7 أزرار كبيرة مع قوائم منسدلة (Popover)، بأيقونات أوضح ومساحة أكبر:
  1. **فتح مخطوط** (+قائمة آخر 5 ملفات مفتوحة)
  2. **بطاقة المخطوط** (توغل عرض/إخفاء + قائمة تحرير/نسخ)
  3. **تصفح** (تكبير حتى 1000%، تدوير، فلاتر: سطوع/تباين/إشباع/حدة/تنقية، عكس ألوان R/G/B مستقلة، مصغّرات أفقية/عمودية)
  4. **ترقيم** (Wizard بـ 3 خطوات: تقسيم → مراجعة → ترقيم + زر «حفظ وتصدير PDF» في النهاية)
  5. **مقابلة (المسطرة)** (شكل: شريط/خط/متوازي، ارتفاع، عرض، محاذاة، زاوية ميلان، لون، شفافية، تعتيم، تمرير تلقائي بسرعة قابلة للضبط مع زر تشغيل/إيقاف)
  6. **تعليق** (إضافة تعليق Ctrl+F، عناوين Ctrl+B، علامات مرجعية)
  7. **تصدير** (ZIP للصور، PDF مفهرس بالعناوين، PDF مضغوط، Word للتعليقات، Word للعناوين، لقطة مع شرح)
- **بطاقة المخطوط الجديدة**: نوع (مفرد/مجموع)، رقم النسخة + المكتبة (استيراد تلقائي من اسم الملف — مثل «الأزهر 325425» → المكتبة=الأزهر، الرقم=325425). حذف الحقول: عناوين أخرى، القرن، الفهرسة، الموضوع، اللغة، نوع الخط، عدد الأوراق، الأبعاد، رابط التحميل. صندوق ملاحظات كبير في كلا الوضعين، وقائمة عناوين مرقّمة في وضع المجموع.
- **علامة مرجعية تلقائية عند الإغلاق**: يُحفظ آخر مكان قراءة عند beforeunload/pagehide/visibilitychange، ويُستعاد عند إعادة فتح الملف.
- **معالجة فعلية للبكسل** للحدة (Unsharp Mask 3×3) وتقليل التشويش (Box Blur 3×3) — تُطبَّق بعد رسم الصفحة على الـcanvas.
- **زوايا وأشكال المسطرة**: skewY لتمييل حتى ±15°، عرض متغيّر، محاذاة يمين/وسط/يسار، أشكال شريط/خط رفيع/متوازي أضلاع.
- **تمرير تلقائي للمسطرة**: RAF loop، سرعة 0-120px/ث، ينتقل تلقائياً للصفحة التالية عند وصول القاع.
- **حذف الميزات غير المرغوبة**: أداة الالتقاط العام WebSnipTool (كلياً)، عرض 3 مخطوطات (بقي 1 أو 2).
- **اختصارات جديدة**: Ctrl+F (تعليق)، Ctrl+B (عنوان)، Ctrl+S (لقطة)، Ctrl+O (فتح)، Ctrl+G (علامات مرجعية).
- **لقطة مع شرح**: خانة اختيارية لإضافة نص أسفل اللقطة عند الحفظ (يُدمج في نفس ملف PNG).
- **مصغّرات أفقية/عمودية**: زر تبديل في قائمة «تصفح».
- **تصدير عناوين إلى Word**: ملف .doc يحتوي جدول بأرقام الأوراق ومستويات العناوين.
- **حزمة Electron v1.5.0 مبنية** (~130MB) — متاحة عبر `/api/download/windows`.

## نقاط تقنية
- شبه-كامل: NSIS makensis يفشل بـEPIPE داخل الحاوية؛ نستخدم win-unpacked + zip يدوي (يعمل كنسخة portable).
- Ruler transform: `skewY(deg)` مع transform-origin: center لدعم الأسطر المائلة.
- Pixel filters: `getImageData/putImageData` بعد الرسم، مع كسول (فقط عند تفعيل أحد الفلاتر) لتجنّب التأخير.

- P2: بحث نصي داخل التعليقات.
- P2: مطابقة نص مطبوع بمخطوط سطر بسطر.
- P2: OCR عربي.
- P2: مزامنة اللوحتين جنباً إلى جنب.
- P2: بحث في المكتبات (الأزهر، مكتبة الملك عبدالعزيز…).

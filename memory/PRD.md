# متصفح المخطوطات — PRD

## المشكلة الأصلية
أداة سطح مكتب متخصصة لباحثي المخطوطات لعرض الصور/PDF بجوار مسطرة أفقية شفافة (تعينهم على القراءة سطراً سطراً). امتدت المتطلبات لتشمل معالجة ملفات ZIP/RAR، والكشف الذكي لتقسيم الصفحات المزدوجة (رَكْتُو/فِرْسو)، وترقيم الأوراق (1/أ، 1/ب)، وبطاقات وصف المخطوط، والتعليق على أسطر بعينها، وأداة قصّ مدمجة، وتبويبات لعدة مخطوطات، وعناوين (فهرس)، ومصغّرات، وتصدير (Word/PDF).

## البنية
- Frontend: React (CRA) — قابل للتغليف كتطبيق Windows Portable عبر Electron.
- Backend: FastAPI — يستضيف ملف التحميل (`/api/download/windows`).
- PDF: `pdfjs-dist` + `pdf-lib` للإنشاء/الفهرسة.
- الأرشيفات: `libarchive.js` (WASM) لدعم ZIP/RAR/7z/TAR داخل المتصفح.
- التخزين: `localStorage` (مُعزَّل لكل لوحة عرض عبر بادئة NS مأخوذة من hash).

## المكوّنات الرئيسية
- `/app/frontend/src/App.js` — نقطة الدخول (SplitView)
- `/app/frontend/src/components/SplitView.jsx` — حاوٍ للعرض جنباً إلى جنب (1/2/3 لوحات مع حدود قابلة للسحب).
- `/app/frontend/src/components/ManuscriptRuler.jsx` — قلب التطبيق (المسطرة، العارض، التبويبات…).
- `/app/frontend/src/components/WebSnipTool.jsx` — أداة الالتقاط من أي شاشة/نافذة وتجميع PDF.
- `/app/frontend/src/components/manuscriptDoc.js` — معالجة الملفات (PDF/صور/ZIP)، التقسيم، التصدير.
- `/app/desktop/main.js` — نقطة Electron مع IPC (`desktopCapturer`, `dialog`, حفظ الملفات).
- `/app/desktop/preload.js` — يعرض `window.msElectron`.
- `/app/backend/server.py` — نقطة `/api/download/windows` لتنزيل الحزمة.

## ما تم إنجازه
- شريط مسطرة أفقي شفاف بألوان/شفافية/ارتفاع قابلة للضبط.
- فتح صور/PDF/ZIP/RAR/7z/TAR محلياً (بلا رفع للسيرفر).
- تقسيم ذكي للصفحات المزدوجة + شريط تمرير يدوي لضبط خط الطي.
- ترقيم الفوليو (1/أ، 1/ب) مع مدى تخصيص للصفحات.
- بطاقة معلومات مخطوط قابلة للتعبئة والنسخ كجدول.
- تعليقات على مستوى السطر مع نسخ العزو (المكتبة، رقم النسخة، ورقة X/أ).
- أداة قصّ (Snip) مع الرسم (إطار، سهم، قلم).
- تبويبات لعدة مخطوطات، شريط مصغّرات جانبي، فهرس عناوين (TOC).
- تصدير Word (.doc) للتعليقات + تصدير PDF مضغوط مفهرس ببوكماركس.
- **[16 يوليو 2026]** عرض جنباً إلى جنب: 1/2/3 مخطوطات في نفس النافذة مع حدود قابلة للسحب لتغيير الأحجام. كل لوحة مستقلة تماماً (localStorage خاص عبر بادئة NS من الـhash).
- **[16 يوليو 2026]** أداة التقاط شاشة عامة (`WebSnipTool`): تدعم أخذ لقطات من أي شاشة أو نافذة، سواء متصفح أو برنامج آخر. تعمل في:
  - سطح المكتب (Electron): تعرض مصادر الشاشة/النوافذ عبر `desktopCapturer` مع صور مصغّرة، حفظ في مجلد يختاره المستخدم عبر `dialog.showOpenDialog` (PNG + PDF مجمّع).
  - المتصفح (Web): يستخدم `getDisplayMedia` مع تنزيل كأرشيف ZIP يحتوي PNG + PDF.
- **[16 يوليو 2026]** حزمة Electron v1.4.0 مبنية (277MB وحدة تشغيل، 128MB مضغوطة) ومتاحة عبر `/api/download/windows`.

## نقاط التصدير الفنية
- **العرض جنباً إلى جنب**: يعتمد على `<iframe src="index.html#ns=A|B|C">` حيث يقرأ ManuscriptRuler الـhash ويضيف بادئة لجميع مفاتيح localStorage (لا يوجد تداخل بين اللوحات).
- **الالتقاط العام**: يعتمد Electron على `session.setDisplayMediaRequestHandler` **غير مطلوب** لأن الأداة تستخدم `getUserMedia({video: {chromeMediaSource: 'desktop', chromeMediaSourceId}})` بعد جلب المصادر عبر IPC.

## المستخدم المستهدف
باحثو ومحققو المخطوطات، طلاب الدراسات العليا، مكتبات المخطوطات، القرّاء المطوّلون للنصوص المصوّرة.

## قائمة الميزات المتبقية (اختيارية)
- P1: إعدادات نظام موحّدة (Ctrl+K لكل الاختصارات).
- P1: مطابقة بين نصّ مطبوع (Word) وصورة مخطوط سطر بسطر.
- P2: OCR للنصوص العربية المخطوطة.
- P2: مزامنة اللوحات جنباً إلى جنب (تحريك المسطرة في اللوحة 1 يحرّكها في اللوحة 2 تلقائياً).
- P2: تكامل مع مكتبات المخطوطات الشهيرة (الأزهر، مكتبة الملك عبدالعزيز…).

## الاختبار
- شاشات اختبار: OK — تبويبات، تقسيم، تصدير، التعليقات، أداة القصّ.
- عرض جنباً إلى جنب: OK — 2 و 3 لوحات (iframes) تعمل، حد فاصل قابل للسحب.
- أداة الالتقاط العامة: OK في وضع المتصفح (getDisplayMedia). في Electron ينبغي اختبارها بعد تشغيل الـexe من قِبَل المستخدم.
